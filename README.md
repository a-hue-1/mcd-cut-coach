## 一句话

输入「我这顿能吃多少卡、有多少钱、要不要吃饱」，它直接给你**能照着点的组合**，并同时告诉你热量、蛋白质和钠——三个数字一起看，避免"看起来健康其实很咸"的坑。

---

## 解决什么问题

想控热量的人在麦当劳面前通常卡在三个地方：

| 痛点 | 现状 | 本 Skill |
|---|---|---|
| **营养表看不懂** | 官网数据是 PDF/网页表格，还要自己按规格换算 | 一条命令出结果，规格自动匹配 |
| **单看热量会踩坑** | 500 kcal 的组合可能钠超全天一半 | 热量 / 蛋白质 / 钠 **三指标并排**，一个都不隐藏 |
| **价格查不到** | 价格随城市、门店、时段浮动 | 走官方 MCP 拿**门店实时价**，没有就标 `—`，绝不瞎编 |

---

## 功能

| 命令 | 作用 | 典型问法 |
|---|---|---|
| `cut` | **减脂推荐**：给热量上限（+ 可选预算/蛋白下限），输出推荐单品与套餐组合 | 「减脂吃麦当劳吃什么」 |
| `rank` | 按价格 / 热量 / 蛋白密度 / 蛋白性价比等 9 个维度排列 | 「按价格排一下麦当劳」 |
| `combo` | 计算任意自定义组合的合计热量与总价 | 「板烧+玉米杯+无糖可乐多少卡」 |
| `compare` | 2~N 个餐品横向对比 | 「巨无霸和麦辣鸡腿堡哪个好」 |
| `price` | 按所在城市门店手工补录价格 | 「我们这儿板烧 22.5」 |
| `refresh` | 把 MCP 拉到的实时数据合并进本地数据集 | 「刷新麦当劳数据」 |

`mcp_client.py` 另提供 `ping` / `tools` / `nutrition` / `meals` / `sync` / `call`，直接对话麦当劳官方 MCP。

## 安装

**前置条件**

1. Python 3.9+（零第三方依赖，无需 `pip install`）
2. 麦当劳 MCP Token → 到 <https://open.mcd.cn/mcp> 手机号登录 → 控制台 → 激活 → 申请

**步骤**

```bash
# 1. 获取代码
git clone https://github.com/a-hue-1/mcd-cut-coach.git
cd mcd-cut-coach

# 2. 注入 Token
export MCD_MCP_TOKEN='你的Token'

# 3. 自检连通性
python skill/scripts/mcp_client.py ping

# 4. 拉取官方营养库 + 门店实时价
python skill/scripts/mcp_client.py sync --store 1420227
```

**作为 Skill 使用（WorkBuddy）**

把 `skill/` 整个目录复制到 `~/.workbuddy/skills/mcd-cut-coach/`，重启后即可用自然语言调用。

MCP 配置见 `mcp-config.example.json`（脱敏，仅 `${MCD_MCP_TOKEN}` 占位符）。

## 使用示例

### 例 1：减脂期，一顿 500 kcal 以内、30 元以内

```bash
python skill/scripts/mcd.py cut --kcal-cap 500 --budget 30 --top 3
```

**输出**

```
【A】推荐单品（≤500 kcal · 蛋白≥20g · 预算≤¥30）
| # | 餐品              | 价格    | kcal | 蛋白 | 脂肪 | 钠 mg | 灯 |
|---|-------------------|---------|------|------|------|-------|-----|
| 1 | 板烧鸡腿堡        | ≈¥22.5 |  404 | 27.0 | 17.0 |  1041 | 🟡 |
| 2 | 麦香鱼            | ≈¥18.0 |  342 | 15.0 | 14.0 |   617 | 🟢 |
| 3 | 吉士蛋麦满分      | ≈¥13.0 |  301 | 17.0 | 12.0 |   705 | 🟢 |

【B】套餐组合（主食 + 小食/甜品 + 饮料，按价格升序）
| # | 组合                                    | 总价    | kcal | 蛋白 | 脂肪 | 钠 mg |
|---|-----------------------------------------|---------|------|------|------|-------|
| 1 | 吉士蛋麦满分 + 玉米杯(小) + 无糖可口可乐(中) | ≈¥30.0 |  390 |   21 |   13 |   762 |
```

### 例 2：按价格升序排列，只看蛋白 ≥ 15 g 的

```bash
python skill/scripts/mcd.py rank --sort price --asc --min-protein 15 --top 8
```

### 例 3：自定义组合核算

```bash
python skill/scripts/mcd.py combo --items "板烧鸡腿堡,玉米杯(小),无糖可口可乐(中)"
```

```
合计：444 kcal · 蛋白 25.0 g · 脂肪 18.0 g · 钠 1077 mg（占全天上限 54%）
```

## 数据来源

| 数据 | 来源 | 说明 |
|---|---|---|
| 热量 / 蛋白质 / 脂肪 / 碳水 / 钠 / 钙 | 麦当劳官方 MCP `list-nutrition-foods` | 权威来源，按规格拆分 |
| 价格 | 麦当劳官方 MCP `query-meals` | 门店实时价；未覆盖项显示 `—` |
| 兜底数据 | 麦当劳官网营养计算器公开数据 | 无 Token 时仍可离线运行 |

**价格标记含义**：`¥` = MCP 门店实测 / `≈¥` = 公开网页参考（±10~20%）/ `—` = 待补录。

## 目标用户

| 人群 | 场景 |
|---|---|
| **身材管理期人群** | 想吃麦当劳但怕热量失控，需要明确"这顿能吃多少、点什么" |
| **健身 / 增肌人群** | 关注蛋白密度与蛋白性价比，在有限热量里吃够蛋白质 |
| **控钠人群** | 需要同时盯住钠含量，避免"低卡高钠"陷阱 |
| **通勤 / 学生党** | 预算有限，要在热量和价格之间找平衡点 |
| **麦当劳 MCP 开发者** | 需要一套可直接复用的 MCP over HTTP 客户端与数据匹配层 |
